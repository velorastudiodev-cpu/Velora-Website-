# Velora logo assets included with this PRD

These files are the founder-supplied logo references. Preserve the originals.

- `velora-wordmark-official-reference.jpg`: official wordmark reference, with a checkerboard pattern baked into the raster.
- `velora-symbol-checkerboard-reference.jpg`: symbol reference, with a checkerboard pattern baked into the raster.
- `velora-symbol-dark-background-reference.png`: symbol reference on a solid dark background.

Important: the checkerboard is part of the first two raster images, not true transparency. Do not place those files directly into the production website with the checkerboard visible. Inspect alpha/background, use a clean official transparent logo if the founder supplies one, or carefully isolate the neutral background while preserving the original mark. Do not redraw or regenerate the logo. Keep these original references unchanged.
