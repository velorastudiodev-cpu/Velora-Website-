# Velora Studio PRD assets

This folder contains founder-supplied Velora logo references and the three screenshots of the feature mindmap.

**Logo note:** some supplied raster references have a checkerboard pattern baked into the pixels; it is not true transparency. Do not display the checkerboard on the production site. Preserve the original files, prefer a clean official transparent asset if available, and only isolate the background on a working copy if the logo can be preserved faithfully.

**Mindmap note:** the screenshots are product-structure references, not public-site design assets. The PRD follows the visible feature hierarchy and phase labels, while clearly treating additional inferred subfeatures as proposals.
